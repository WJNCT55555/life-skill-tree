# 人生技能树 · 301 件从没做过的事

> 给「失眠 · 疲惫 · 沉溺短视频」状态设计的一套人生任务系统。
> 规则只有一条：**每天点亮一个你这辈子没做过的节点。**

---

## 这是什么

一个**单文件网页应用**，不需要安装、不需要注册、不需要联网，所有数据存在你自己的浏览器里。

```
9 个领域 · 27 条分支 · 301 个节点
每个节点分 8 层：入门 → 熟练 → 进阶 → 硬仗 → 大师 → 异想 → 狂想 → 远征
其中 105 个构成 15 周主线，其余 196 个是备选池
每个节点配 3 个追问，共 903 个
39 个成就
```

### 九个领域

| 领域 | 三条分支 |
|---|---|
| 🔨 手工 | 自理 · 手作 · 维修 |
| ⚔️ 体魄 | 耐力 · 极限 · 协作 |
| 🧠 智识 | 逻辑 · 求知 · 突破 |
| 🎨 审美 | 创作 · 写作 · 感官 |
| 🤝 魅力 | 表达 · 亲密 · 边界 |
| 📜 能略 | 财务 · 秩序 · 取舍 |
| 🍲 品味 | 饮食 · 独处 · 探索 |
| 🌙 心性 | 睡眠 · 静观 · 清醒 |
| 🕯️ 信仰 | 生死 · 意义 · 利他 |

**魅力**是和人打交道的能力，**能略**是管资源的能力。**信仰**回答的是「我为什么活着」——写遗嘱、想象自己的葬礼、为自己写讣告、种一棵能活很久的树、做一件死后还能留下的事。

### 任务长什么样

不是「看一场电影」这种愿望，是当天能执行的具体动作：

| 任务 | 怎么做 |
|---|---|
| 用左手过一天 | 吃饭、刷牙、开门、写字全用左手。做不到的事就放慢速度做 |
| 给同一棵树拍一年 | 找一棵每天路过的树，今天拍第一张，然后每月同一天拍一张，连续十二个月 |
| 写一封一百年后的信 | 写给 2126 年的某个人：现在的街道、你用的东西、你担心的事。写清日期地点，封好 |
| 在户外闭眼走五十步 | 同伴在旁看着，凭脚底和风向判断方向，睁眼后看偏离多少 |
| 抵达火地岛 | 飞乌斯怀亚——地球最南的城市，去南极的船都从这里出发 |

### 体力系统

每天回满 **15 点**，节点按时长扣 **3 / 5 / 10 / 15** 点：

| 时长 | 体力 |
|---|---|
| ≤15 分钟 | 3 点 |
| ≤30 分钟 | 5 点 |
| ≤60 分钟 | 10 点 |
| >60 分钟 | 15 点 |

**体力耗尽 = 当天达标**（一个硬仗、或 10+5、或 5+5+5 都行）。还想做就是**超额完成**，每天额外奖励宝石并计入成就。体力不累积到明天。

### 防放弃机制

- **前 10 个只发轻量节点**——先让动作长在你身上，再谈难度
- **熔断卡**：连续点亮每满 7 天攒 1 张，断一天用掉不清零
- **复活卡 3 张**
- **睡前保护**：20:00-02:00 只发轻量或睡前向节点
- **断签文案不羞辱你**：羞耻感是习惯系统最大的杀手

## 怎么用

### 在线用

直接打开部署好的网址。手机浏览器「添加到主屏幕」，之后像 App 一样全屏打开、离线可用。

### 离线用

下载 `index.html` 双击即可。拷到手机、U 盘、网盘都能跑。

### 数据

所有记录存在**你自己的浏览器**（localStorage），不上传任何服务器。
**每周点一次「设置 → 导出备份」，把 JSON 存好。** 换设备靠导出/导入同步。

## 改动与重新构建

改任务就改 `v3/nodes.mjs`，然后：

```powershell
node v3/build.mjs
```

会重新生成 `index.html` 和 `docs/科技树总览.md`。

**构建脚本会把关**，写错直接拒绝并指出是哪一条：

- 领域必须 9 个、分支必须 27 条、节点 ≥301
- 每条分支层级从第 1 层连续，每层最多 2 个节点
- **任务名 4-16 字且不带标点**（要像个钩子，不要写成标签）
- **描述 ≥25 字**（防止写出「看一场电影」这种愿望级条目）
- 主题周必须刚好 15 × 7 = 105 天
- 成就 id 与条件不得重复

> 这套校验不是装饰——开发过程中它拦下过 8 次错误（任务名带标点、描述太短、层级超 2 个、题库不够、分支数不对、ID 重复、领域键缺失、主题周分配不满）。

### 文件结构

```
.
├─ index.html            ← 成品（单文件，部署这个就行）
├─ docs/
│  ├─ 怎么用.md           ← 使用说明
│  ├─ 科技树总览.md       ← 301 个节点清单（可打印）
│  ├─ 项目历程.md         ← 版本变化、踩过的坑、设计取舍
│  └─ README.md          ← 项目总览
└─ v3/                   ← 源码
   ├─ nodes.mjs          ← 题库（唯一真相源）
   ├─ data.mjs           ← 九领域 / 27 分支 / 8 层 / 体力规则
   ├─ template.html      ← 界面（终端风格 + 三色主题）
   ├─ build.mjs          ← 校验 + 合成单文件
   └─ serve.mjs          ← 本地预览服务器
```

## 部署

纯静态站点，`index.html` 就是全部。

**Cloudflare Pages**：Workers & Pages → Create → Pages → 连接这个仓库 → 构建设置留空
（Build command 留空、Build output directory 填 `/`）→ Deploy。

不用服务器、不用备案、自带 HTTPS。

## 设计取舍

**为什么题库要 301 个，而主线只有 105 个？**
剩下的 196 个是备选池，保证每周有 2-3 倍的选择余量。**题库如果只有 105 个，「每天一件新事」就变成「每天一件被指定的事」。**

**为什么删掉了「属性」层？**
早期版本给每条分支挂了属性标签（勇气/逻辑/创造…），但它和分支是 1:1 对应的——**信息完全重合，等于同一件事说了两遍**。现在分支名就是唯一的能力维度。

**为什么体力不累积到明天？**
能攒就会变成「周末补五天」，系统就退化成待办清单了。

**为什么信仰单独成一个领域？**
前八个领域都在回答「我能做什么」，只有信仰回答「我为什么活着」。
